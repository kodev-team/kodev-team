# KODEV

We review AI-built web apps (Lovable, Bolt, Replit, Cursor) on Supabase before real users arrive, fix the most
important problems and retest them. We write down what we checked, when, and what we found. We only work with the
app owner's written permission.

## Free tool
- [supabase-check](https://github.com/kodev-team/supabase-check): a read-only SQL check for common data-access
  mistakes in your own Supabase project. One file, no install, nothing leaves your project.
